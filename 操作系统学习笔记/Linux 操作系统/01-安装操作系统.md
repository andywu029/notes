# 使用 VirtualBox 安装

&emsp;&emsp;首先需要下载 `Centos7` 的镜像文件，然后打开 `VirtualBox` 软件，点击【新建】按钮创建虚拟机：

![](./images/01/01.png)

&emsp;&emsp;在弹出的设置框中设置虚拟机名称和操作系统的基本信息：

![](./images/01/02.png)

&emsp;&emsp;设置虚拟机的用户名和密码：

![](./images/01/03.png)

&emsp;&emsp;点击【完成】按钮，然后双击运行创建的虚拟机：

![](./images/01/04.png)

&emsp;&emsp;如果出现如下的对话框，重新选择系统中的 `Centos7` 镜像所在的位置，点击【挂载并尝试重启】：

![](./images/01/05.png)

&emsp;&emsp;接下来重新运行虚拟机，接下来设置语言为【中文-简体中文】：

![](./images/01/06.png)

&emsp;&emsp;在接下来的页面中设置安装位置：

![](./images/01/07.png)

&emsp;&emsp;点击图中的【安装位置】按钮，打开安装位置设置的页面，如下图设置点击【完成】即可：

![](./images/01/08.png)

&emsp;&emsp;接下来设置虚拟机的网络，点击如下图的【网络和主机名】按钮：

![](./images/01/09.png)

&emsp;&emsp;如下图所示，选择打开网络，然后点击【完成】：

![](./images/01/10.png)

&emsp;&emsp;根据需要选择需要安装的软件系统的类型（这里选择的是【最小安装】）：

![](./images/01/11.png)

&emsp;&emsp;完成以上设置后，点击【开始安装】进行安装。接下来根据需要设置 ROOT 用户的密码和创建用户（<font color=red>可以不创建用户，但需要设置 ROOT 密码</font>）：

![](./images/01/12.png)

&emsp;&emsp;等待虚拟完成系统的安装操作，安装完成后会提示重启，点击【重启】进入到下面的页面就表示安装成功了：

![](./images/01/13.png)

&emsp;&emsp;使用 root 账号和设置的密码进行登录：

![](./images/01/14.png)

&emsp;&emsp;接下来关闭虚拟机，然后右键虚拟机进入到虚拟机的设置页面，点击【网络】进入到网络设置的面板：

![](./images/01/15.png)

&emsp;&emsp;设置网卡1为 <font color=red>网络地址转换</font>，设置网卡2为 <font color=red>仅主机模式</font>：

![](./images/01/16.png)

![](./images/01/17.png)

![](./images/01/18.png)

&emsp;&emsp;接下来可以使用 `ip addr show` 命令查看安装好的操作系统的 `ip` 地址：

&emsp;&emsp;然后打开 `FinalShell` 工具，通过添加连接按钮添加新的连接地址：

![](./images/01/20.png)

&emsp;&emsp;按照下图设置名称、主机、端口（22）、用户名和密码：

![](./images/01/21.png)

&emsp;&emsp;设置完成后双击进入到连接界面：

![](./images/01/22.png)

&emsp;&emsp;当我们使用 `YUM` 下载软件时候，默认 `Centos` 镜像地址中下载可能出现失败的情况，因此需要设置 `YUM` 的镜像源。因为我们在安装 `Centos` 的时候选择的是最小安装，因此系统中并没有 `wget` 工具，可以在 <font color=green >http://mirrors.aliyun.com/centos/7/os/x86_64/Packages/</font>  阿里云上下载 `wget-1.14-18.el7_6.1.x86_64.rpm` 工具，然后在 `/usr/local` 目录下创建 `wget` 目录，并将 `wget-1.14-18.el7_6.1.x86_64.rpm` 安装包上传到该目录中，并通过下面的命令进行安装：

```shell
rpm -ivh wget-1.14-18.el7_6.1.x86_64.rpm
```

![](./images/01/23.png)

&emsp;&emsp;接下来通过以下命令切换 `Linux` 的下载源：

```shell
# 备份原来的文件
sudo cp /etc/yum.repos.d/CentOS-Base.repo /etc/yum.repos.d/CentOS-Base.repo.backup

# 使用 wget 下载设置新的下载源
sudo wget -O /etc/yum.repos.d/CentOS-Base.repo http://mirrors.aliyun.com/repo/Centos-7.repo
```

&emsp;&emsp;初始设置完成后，需要清理缓存并更新 `YUM`，命令如下：

```shell
sudo yum clean all
sudo yum makecache
```

&emsp;&emsp;接下来可以更新系统中的所有的软件包：

```shell
# 更新所有系统中所有的软件包
sudo yum update

# 清理 yum 的缓存来释放一些磁盘空间
sudo yum clean all
```
